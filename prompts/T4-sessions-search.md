# Task: Search/filter on the Sessions page

The Sessions page lists past sessions. Add a search box that filters the
list.

Requirements:

- A text input at the top of the Sessions list filters sessions as the
  user types (no submit button needed).
- Match case-insensitively against the session title/name and date.
- Show a clear empty-state message when no session matches.
- Clearing the input restores the full list.
- Keep the existing visual style of the page (same component library).

Done when `npm test` and `npm run typecheck` pass.
